---
title: 过滤器
---

*自 v2.6.0 起可用 · 在 v3.0.0、v3.3.0 中增强*

Umami 内置了报告功能，帮助您深入了解数据的各个部分。通过通用过滤，您可以在所有屏幕/报表中应用条件，以便进行一致的分析。
细分功能让您可以根据共享属性或行为对用户进行分组。群组功能在此基础上更进一步，随时间分析用户群，帮助您跟踪留存率、性能和长期趋势。

## 可用的过滤器

过滤器在过滤面板中按类别分组。

| 类别 | 过滤器 | 描述 |
| --- | --- | --- |
| URL | Path | 访问页面的 URL 路径。 |
| URL | Query | URL 的查询字符串部分（例如，`?ref=homepage`）。 |
| URL | Page Title | 浏览器标签页中显示的页面 HTML 标题。 |
| Sources | Referrer | 将访问者引导到您网站的来源。 |
| Location | Country | 基于地理位置的访问者国家/地区。 |
| Location | Region | 访问者所在的州、省或地区。 |
| Location | City | 访问者所在的城市。 |
| Environment | Browser | 访问者使用的网页浏览器（例如：Chrome、Safari、Firefox）。 |
| Environment | OS | 访问者设备的操作系统（例如：Windows、macOS、iOS、Android）。 |
| Environment | Device | 使用的设备类型，例如桌面、平板或移动设备。 |
| UTM | UTM Source | 流量来源（例如，`google`、`newsletter`）。 |
| UTM | UTM Medium | 营销媒介（例如，`cpc`、`email`）。 |
| UTM | UTM Campaign | 活动名称。 |
| UTM | UTM Content | 具体广告或链接内容。 |
| UTM | UTM Term | 付费搜索关键词。 |
| Other | Hostname | 访问该页面的域名。 |
| Other | Distinct ID | 您为访问者分配的自定义标识符。请参见 [独立 ID](/docs/distinct-ids)。 |
| Other | Tag | 您为数据分配的标签或关键词。请参见 [标签](/docs/tags)。 |
| Other | Event | 用户触发的自定义事件（例如按钮点击、表单提交、视频播放）。 |

## 属性过滤器

除了上述标准字段外，过滤面板还提供了专门的选项卡，用于根据自定义数据进行过滤：

- **Session data** — 根据您保存的任何 [session data](/docs/tracker-functions#session-data) 属性进行过滤（例如 `plan`、`company`）。每个报表页面都可用。
- **Event properties** — 根据任何自定义事件属性进行过滤。仅在 **Events** 页面上可用，因为这些过滤器限定于特定事件。

![image](/images/docs/filter-property.png)

每个属性过滤器都具有类型感知能力：可用的运算符（等于、包含、之前/之后等）取决于该属性保存时使用的是字符串、数字、布尔值、日期还是数组。

## 匹配模式

应用多个过滤器时，使用 **匹配** 开关来控制条件如何组合：

| 模式 | 描述 |
| --- | --- |
| 全部 | 访问者必须匹配每个条件（逻辑 AND）。 |
| 任意 | 访问者至少必须匹配一个条件（逻辑 OR）。 |

## 过滤器运算符

每个过滤条件都支持以下运算符：

| 运算符 | 描述 |
| --- | --- |
| 等于 | 精确匹配。 |
| 不等于 | 排除精确匹配。 |
| 包含 | 值包含指定字符串。 |
| 不包含 | 值不包含指定字符串。 |
| 匹配正则 | 值匹配所提供的正则表达式。 |
| 不匹配正则 | 值不匹配所提供的正则表达式。 |

登录 Umami 后，在侧边栏点击 **网站**。

![图像](/images/docs/navbar.png)

![图像](/images/docs/website-edit.png)

![图像](/images/docs/filter-add.png)
