---
title: 唯一标识符
---

*自 v2.18.0 版本起可用*

Distinct ID 是分配给用户的唯一标识符，无论是匿名状态还是登录时。
这使您能够将操作（页面浏览、点击、转化）与单个用户在多个会话中进行关联。
如需更全面的会话识别方式，请参阅 [会话数据](/docs/tracker-functions#session-data)。

## 使用场景

- 准确归因用户行为。
- 连接多个会话或设备中的事件。
- 识别回访用户与新用户。
- 基于用户历史构建旅程和用户画像。

## 使用方法

您可以使用 `umami.identify()` 跟踪器函数设置 Distinct ID：

```js
umami.identify({ id: 'bob@aol.com' });
```

或者在使用 [发送统计信息](/docs/api/sending-stats) API 时，直接将 **id** 属性添加到事件 payload 中：

```json
{
  "payload": {
    "hostname": "your-hostname",
    "language": "en-US",
    "referrer": "",
    "screen": "1920x1080",
    "title": "dashboard",
    "url": "/",
    "website": "your-website-id",
    "id": "bob@aol.com"
  },
  "type": "event"
}
```

**id** 属性有 50 个字符的限制。如果您的标识符较长，请考虑使用哈希值或缩短版本。
