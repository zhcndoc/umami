*自 v2.0.0 版本起可用*

Umami 允许您创建独立的账户，以便您可以为朋友或客户托管数据。

## 角色

User roles and related permissions.

| 角色 | 权限 |
| --- | --- |
| 管理员 | 所有权限。 |
| 用户 | 除管理员控制台外的所有权限。 |
| 仅查看 | 仅可查看。 |

使用管理员账号登录 Umami，点击侧边导航中的个人资料按钮，然后点击 **管理员**。

Only **Admin** users can access the **Admin** console.

![image](/images/docs/navbar-settings.png)

然后导航至 **用户（Users）** 并点击 **创建用户（Create user）** 按钮。

![image](/images/docs/user-create.png)

填写表单详情后，点击 **保存（Save）** 按钮。

![image](/images/docs/user-create-form.png)

新账号将拥有独立的仪表盘和网站，与 **管理员** 账号分开。
