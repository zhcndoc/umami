---
title: 导入数据
---

Umami Cloud 支持导入您现有的分析数据，以便您可以在不丢失历史记录的情况下进行迁移。

数据导入功能适用于 **Pro** 计划用户。导入过程由我们的团队处理，以确保数据完整性和正确的映射。

## 支持的来源

- 自托管 Umami 实例（PostgreSQL 数据库导出）
- CSV 数据导出

## 如何请求导入

1. 从您现有的分析平台 [导出您的数据](/docs/cloud/export-data)，或准备一个包含您数据的 CSV 文件。
2. 联系 [support@umami.is](mailto:support@umami.is)，并提供有关您的数据源和数据量的详细信息。
3. 我们的团队将协调导入过程，并在完成后通知您。

导入期间，您在 Umami Cloud 中的现有数据不会受到影响。
