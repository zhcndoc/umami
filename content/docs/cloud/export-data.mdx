---
title: 导出数据
---

Umami 允许您将数据从 Umami Cloud 导出为 CSV 格式（通过 gzip 压缩）。

导出内容包括所选网站收集的所有分析数据，例如页面浏览量、事件、会话和事件数据。导出一次处理一个网站。如果您有大量网站或大量数据需要导出，请联系 [support@umami.is](mailto:support@umami.is)。

## 从 Umami Cloud 导出数据

登录后，点击侧边导航中的个人资料按钮，然后点击 **设置**。

![image](/images/cloud/navbar-settings.png)

导航至 **数据**，然后点击 **导出** 按钮。

![image](/images/cloud/export-data.png)

填写表单信息后，点击 **导出** 按钮。

![image](/images/cloud/export-form.png)

导出完成后，您将收到一封包含数据下载链接的电子邮件。

![image](/images/cloud/export-email.png)
