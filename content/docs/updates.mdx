## Source Code

Before running these commands, make sure you are in the Umami project directory.

Pull the latest changes from the Git repository:

```shell
git pull
```

Install any new or updated dependencies:

```shell
pnpm install
```

Rebuild the project:

```shell
pnpm build
```

Finally, restart the application:

```shell
pnpm start
```

If you are using a process manager like PM2, restart the process instead:

```shell
pm2 restart umami
```

## Docker

拉取最新镜像：

```shell
docker pull docker.umami.is/umami-software/umami:latest
```

然后重启容器以使用新镜像。如果使用 Docker Compose：

```shell
docker compose down
docker compose up -d
```

## 升级后刷新数据库统计信息

重大升级（例如迁移到 v3）会运行模式迁移，这可能会使 PostgreSQL 的查询规划器保留过时的统计信息，导致在大型实例上仪表板查询比预期更慢。运行 `ANALYZE` 来刷新它们：

```sql
ANALYZE;
```

这可以安全地在正在运行的数据库上执行，并且会快速完成。之后，仪表板查询应恢复到预期速度。
