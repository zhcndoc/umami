title: 指标定义
---

所有 Umami 默认收集的指标及其高层定义。

---

## 事件指标

事件指标用于识别用户的唯一事件。每个事件都存储为一个唯一的 UUID，称为事件 ID。

| Metric | Description |
| --- | --- |
| Website ID | 用于标识你网站的唯一 UUID 值，包含在负载中。 |
| Hostname | 负载中包含的 Location [hostname](https://developer.mozilla.org/en-US/docs/Web/API/Location/hostname) 属性。 |
| URL | 负载中包含的 URL [pathname](https://developer.mozilla.org/en-US/docs/Web/API/URL/pathname) 和 [search](https://developer.mozilla.org/en-US/docs/Web/API/URL/search) 属性的组合。 |
| Query parameters | 请求发送后从 URL 中提取的 [search](https://developer.mozilla.org/en-US/docs/Web/API/URL/search) 属性。 |
| Referrer | 负载中包含的 Document [referrer](https://developer.mozilla.org/en-US/docs/Web/API/Document/referrer) 属性。如果 referrer 包含 hostname，则该值会替换为前一个 URL。 |
| Title | 负载中包含的 Document [title](https://developer.mozilla.org/en-US/docs/Web/API/Document/title) 属性。 |
| Event Name | 页面上触发的自定义事件名称（例如 `signup-button`）。 |
| Tag | 通过 tracker 的 `data-tag` 属性附加到事件上的可选标签。 |

## 会话指标

会话指标用于识别用户的唯一会话。每个会话都存储为一个唯一的 UUID，称为会话 ID。

| 指标 | 描述 | 示例 |
| --- | --- | --- |
| 浏览器 | 从 [User-Agent](https://developer.mozilla.org/en-US/docs/Web/HTTP/Headers/User-Agent) 中提取的浏览器名称。 | Chrome、Firefox、Safari、Edge |
| 操作系统 | 从 [User-Agent](https://developer.mozilla.org/en-US/docs/Web/HTTP/Headers/User-Agent) 中提取的操作系统名称。 | Windows 10、macOS、Linux、Android、iOS |
| 设备 | 根据 **OS** 和 **screen** 的组合识别出的设备名称。 | 笔记本电脑、台式机、手机、平板电脑 |
| 屏幕 | 负载中包含的 [Screen](https://developer.mozilla.org/en-US/docs/Web/API/Screen) 宽度和高度属性。 | 1920x1080、1280x960 |
| 语言 | 负载中包含的 Navigator [language](https://developer.mozilla.org/en-US/docs/Web/API/Navigator/language) 属性。 | 英语、中文、德语、法语 |
| 区别 ID | 通过 `umami.identify()` 分配给访客的自定义标识符。参见 [Distinct IDs](/docs/distinct-ids)。 | `user-123`、`abc@example.com` |

## 地理位置指标

地理位置指标来自于不同来源，取决于请求头。发送请求的 IP 地址用于获取这些指标，但不会被存储。

- `Cloudflare`：[HTTP 请求头](https://developers.cloudflare.com/fundamentals/reference/http-request-headers/#docs-content)
- `Vercel`：[地理位置头](https://vercel.com/guides/geo-ip-headers-geolocation-vercel-functions)
- `MaxMind`：[Geolite 数据库](https://dev.maxmind.com/geoip/geolocate-an-ip)。

| 指标 | 描述 | 示例 |
| --- | --- | --- |
| 国家 | 符合 ISO-3166 标准的国家名称。 | 美国、中国、德国、法国 |
| 地区 | 符合 ISO-3166-2 标准的地区（细分区域）名称。 | 加利福尼亚、安大略、巴伐利亚、法兰西岛 |
| 城市 | 城市名称。 | 旧金山、多伦多、慕尼黑、巴黎 |

## UTM 参数

UTM 参数会从 URL 查询字符串中提取，并随每个事件一起存储。

| 指标 | 描述 |
| --- | --- |
| UTM Source | 标识流量来源（例如 `google`、`newsletter`）。映射到 `utm_source`。 |
| UTM Medium | 标识营销媒介（例如 `cpc`、`email`）。映射到 `utm_medium`。 |
| UTM Campaign | 标识活动名称。映射到 `utm_campaign`。 |
| UTM Content | 标识特定广告或链接内容。映射到 `utm_content`。 |
| UTM Term | 标识付费搜索关键词。映射到 `utm_term`。 |

## 广告点击 ID

当 URL 查询参数中存在广告点击 ID 时，会自动捕获。它们用于将转化归因到付费广告活动。

| 指标 | 描述 |
| --- | --- |
| gclid | Google Click ID，由 Google Ads 添加。 |
| fbclid | Facebook Click ID，由 Meta Ads 添加。 |
| msclkid | Microsoft Click ID，由 Microsoft Advertising 添加。 |
| ttclid | TikTok Click ID，由 TikTok Ads 添加。 |
| li_fat_id | LinkedIn First-Party Ad Tracking ID，由 LinkedIn Ads 添加。 |
| twclid | Twitter/X Click ID，由 X Ads 添加。 |

## 核心 Web 指标

Core Web Vitals 是从浏览器收集并与每个事件一同存储的性能指标。

| 指标 | 描述 |
| --- | --- |
| LCP | [最大内容绘制](https://web.dev/articles/lcp) — 最大可见元素渲染完成所用时间（ms）。 |
| INP | [交互到下一次绘制](https://web.dev/articles/inp) — 页面对用户交互的响应能力（ms）。 |
| CLS | [累计布局偏移](https://web.dev/articles/cls) — 衡量视觉稳定性；得分为 0 表示没有意外的布局偏移。 |
| FCP | [首次内容绘制](https://web.dev/articles/fcp) — 首个内容在屏幕上渲染完成所用时间（ms）。 |
| TTFB | [首字节时间](https://web.dev/articles/ttfb) — 从请求发出到从服务器接收到第一个字节所用时间（ms）。 |

## 计算指标

计算指标是每个网站的总计和唯一数据的组合。

| 指标 | 定义 |
| --- | --- |
| 浏览量 | 从你的访客那里收集到的事件总数。 |
| 访客 | 会话的唯一数量。会话是使用网站 ID、主机名、User-Agent 等数据的哈希值，以及每个月初都会变化的轮换盐值来计算的。 |
| 访问 | 访问的唯一数量。访问是用户会话中更细粒度的范围。访问是使用会话 ID 的哈希值和每小时开始时变化的轮换盐值来计算的。访问可以跨越按小时划分的时间间隔。 |
| 跳出率 | 当一次访问只有 1 个事件时，就定义为一次跳出。用户进入网站后，最初会生成一次浏览，然后离开。跳出率通过将跳出总数除以访问唯一数量来计算。 |
| 访问时长 | 网站上花费的总时间除以访问唯一数量。总时间只对访问超过一个页面的访客进行计算。每次访问中第一个和最后一个事件时间戳之间的差值会累计为持续时间。 |
