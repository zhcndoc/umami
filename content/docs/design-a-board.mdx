---
title: 设计看板
---

*自 v3.1.0 起可用*

## 设计模式

打开看板并点击 **设计** 按钮进入设计模式。在设计模式下，您可以添加行、调整列并放置组件。

![image](/images/docs/board-design.png)

## 添加行和列

点击 **添加行** 按钮插入新行。每行最多可容纳 **4 列**。点击行内的 **添加列** 按钮可进一步拆分。

![image](/images/docs/board-add-row.png)

## 添加组件

点击 **选择组件** 按钮打开组件选择器。选择组件类型并配置其设置，然后点击 **保存** 进行放置。

![image](/images/docs/board-component.png)

## 组件

| 组件 | 分组 | 描述 | 看板类型 |
| --- | --- | --- | --- |
| 指标栏 | 流量 | 关键指标：浏览量、访客数、跳出次数、网站停留时间。 | 全部 |
| 访客图表 | 流量 | 一段时间内的页面浏览量和访客数。 | 全部 |
| 指标表格 | 流量 | 按维度划分的指标表格。 | 全部 |
| 世界地图 | 流量 | 访客的地理分布。 | 全部 |
| 每周流量 | 流量 | 按日期和小时显示的流量热力图。 | 仅网站 |
| 事件指标栏 | 事件 | 关键指标：访客数、访问次数、事件数、唯一事件数。 | 仅网站 |
| 事件图表 | 事件 | 一段时间内的自定义事件。 | 仅网站 |
| 目标 | 行为 | 已保存目标的转化进度。 | 仅网站 |
| 漏斗 | 行为 | 已保存漏斗的步骤转化率。 | 仅网站 |
| 实时指标栏 | 实时 | 实时浏览量、访客数、事件数和国家数。 | 仅网站 |
| 实时图表 | 实时 | 按分钟显示的实时访客数和页面浏览量。 | 仅网站 |
| 活跃用户 | 实时 | 当前在线的访客。 | 仅网站 |
| UTM | 增长 | 单个 UTM 参数的列表和饼图。 | 仅网站 |
| 收入指标栏 | 收入 | 收入摘要：总收入、AOV、ARPU、订单数和客户数。 | 仅网站 |
| 收入图表 | 收入 | 一段时间内的收入。 | 仅网站 |
| 收入指标表格 | 收入 | 按来源或位置划分的收入明细。 | 仅网站 |
| 文本 | 内容 | 自由格式的文本内容。 | 全部 |

标记为 **仅网站** 的组件需要网站数据源。在混合看板中，每个组件都有自己的数据源选择器，因此当您将网站选为组件的数据源时，这些组件便可用。

目标、漏斗、UTM、实时、收入和事件指标组件自 v3.2.0 起可用。

## 调整行和列大小

可以通过拖动行和列之间的分隔线来调整行高和列宽。
