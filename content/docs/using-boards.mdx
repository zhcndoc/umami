---
title: 使用看板
---

*自 v3.1.0 版本起可用*

看板是可自定义的仪表板，可让您以灵活的网格布局排列分析小部件。
您可以创建限定于特定网站、像素或链接的看板，也可以在单个视图中混合来自多个来源的组件。
看板可以与团队成员共享，或通过分享链接公开。

## 看板类型

| 类型 | 描述 |
| --- | --- |
| `mixed` | 无需必需实体的开放看板。可混合来自多个网站、像素和链接的组件。 |
| `website` | 作用域限定为特定网站。解锁仅适用于网站的组件。 |
| `pixel` | 作用域限定为特定像素。显示该像素收集的指标。 |
| `link` | 作用域限定为特定链接。显示该链接的点击和流量指标。 |

## 查看看板

点击 **看板** 列表中的看板名称即可打开。您将看到所有组件均按照设计期间定义的布局排列。使用日期范围选择器更改看板上所有组件的时间段。

## 管理看板

- 要创建新看板，请参阅 [添加看板](/docs/add-a-board)。
- 要自定义布局并添加组件，请参阅 [设计看板](/docs/design-a-board)。
- 要公开分享看板，请参阅 [添加看板 - 分享看板](/docs/add-a-board#share-a-board)。
