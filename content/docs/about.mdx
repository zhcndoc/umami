## 什么是 Umami Analytics？

Umami 是一个开源、注重隐私的 Google Analytics 替代方案。  
Umami 为您提供了一个强大的网页分析解决方案，同时不会侵犯用户的隐私。  
此外，当您自行托管 Umami 时，您可以完全掌控您的数据。

![图片](/images/docs/screenshot.png)

## 主要功能

- **注重隐私** - 无 Cookie，不收集个人数据，开箱即符合 GDPR 和 CCPA 规定。
- **轻量级追踪** - 小巧的追踪脚本，不会拖慢您的网站。
- **自定义事件** - 使用自定义事件数据追踪页面浏览之外的任何用户操作。
- **看板** - 构建自定义仪表板，可视化最重要的指标。
- **洞察** - 内置报告，包括漏斗、留存率、UTM 追踪、目标等。
- **会话回放** - 记录并重放用户会话，以便在上下文中理解行为。
- **性能监控** - 追踪 Core Web Vitals 和其他性能指标。
- **团队** - 共享访问权限并与团队成员协作。
- **API** - 完整的 API 访问权限，用于构建自定义集成和自动化。
- **自托管或云端** - 在您自己的基础设施上运行或使用 [Umami Cloud](/docs/cloud)。
