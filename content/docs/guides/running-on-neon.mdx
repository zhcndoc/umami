---
title: 在 Neon Postgres 上运行
---

[Neon](https://neon.tech/) 是一个全托管的无服务器 Postgres 服务。

## 设置

1. 在离你托管 Umami 项目位置较近的区域，使用给定名称在 Neon 上创建一个项目。
   - 你也可以使用 Neon CLI 创建 Neon 项目：`npx neonctl projects create`。连接字符串将打印到控制台。
2. 获取启用池化连接的数据库连接字符串。它看起来应类似于：`postgres://user:passwd@endpoint-pooler.region.aws.neon.tech/neondb`。
   - 你也可以使用 Neon CLI 获取连接字符串：`npx neonctl connection-string --project-id <project-id> --pooled`。
3. **重要：** 在你刚复制的连接字符串后面添加 `?pgbouncer=true&connect_timeout=10`。
4. 将 `DATABASE_URL` 添加到你的 `.env` 文件中：
   ```text
   DATABASE_URL=postgres://user:passwd@endpoint-pooler.region.aws.neon.tech/neondb?pgbouncer=true&connect_timeout=10
   ```
5. 现在你应该能够检查数据库连接并更新架构（运行 `yarn run build-db && yarn run update-db`）。
6. 按照 **入门指南** 中的说明，从 [登录](/docs/login) 步骤开始，并确保更改默认密码。
