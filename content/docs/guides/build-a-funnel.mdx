---
title: 构建转化漏斗
---

漏斗可视化了用户迈向目标的逐步路径，确切地显示他们在哪里流失。本指南将介绍如何构建和解读有效的漏斗。

## 规划您的漏斗

在 Umami 中创建漏斗之前，定义用户应采取的步骤。一个好的漏斗包含 2-7 个代表清晰用户旅程的顺序步骤。

### 常见漏斗示例

**电商购买流程：**

| 步骤 | 类型 | 值 |
| --- | --- | --- |
| 1 | 查看页面 | `/products` |
| 2 | 触发事件 | `add-to-cart` |
| 3 | 查看页面 | `/checkout` |
| 4 | 触发事件 | `purchase-complete` |

**SaaS 注册流程：**

| 步骤 | 类型 | 值 |
| --- | --- | --- |
| 1 | 查看页面 | `/` |
| 2 | 查看页面 | `/pricing` |
| 3 | 触发事件 | `signup` |
| 4 | 触发事件 | `onboarding-complete` |

**内容互动：**

| 步骤 | 类型 | 值 |
| --- | --- | --- |
| 1 | 查看页面 | `/blog*` |
| 2 | 查看页面 | `/docs*` |
| 3 | 触发事件 | `signup` |

注意：您可以使用 URL 通配符（例如 `/blog*`）来匹配任何以该路径开头的页面。

## 设置事件跟踪

页面查看步骤会自动跟踪。对于基于事件的步骤，请将跟踪代码添加到您的网站：

```html
<button data-umami-event="add-to-cart">添加到购物车</button>
```

```js
// 用于编程式事件
umami.track('purchase-complete', { revenue: 79.99, currency: 'USD' });
```

## 创建漏斗

1. 导航到您的网站并打开 **漏斗** 洞察。
2. 点击 **添加漏斗** 并给它一个描述性的名称。
3. 点击 **添加** 以定义每个步骤：
   - 选择 **查看页面** 或 **触发事件**。
   - 输入 URL 或事件名称。
4. 设置 **时间窗口**：连续步骤之间允许的最大时间（以分钟为单位）。如果用户在任何两个步骤之间花费的时间超过此限制，则不计入通过漏斗的进度。
   - **短时间窗口**（15-30 分钟）适用于用户在一次会话中完成流程的结账流程。
   - **较长时间窗口**（1440 分钟 = 24 小时）更适合用户可能稍后返回的考虑型漏斗。
5. 点击 **保存** 并运行洞察。

## 解读结果

漏斗显示：

- 每个步骤的 **用户数**：有多少用户到达了该点。
- 步骤之间的 **流失率**：未继续操作的用户百分比。
- **整体转化率**：完成所有步骤的用户 ÷ 进入步骤 1 的用户。

### 需要注意什么

- **最大流失**：流失率最高的步骤是您最大的机会。如果 60% 的用户在结账时放弃，请专注于简化该页面。
- **意外模式**：如果某个步骤的流失率为 0%，可能范围太广。如果某个步骤的流失率为 99%，跟踪配置可能有误。
- **窗口敏感性**：如果您的转化率非常低，请尝试增加时间窗口。用户可能会跨多个会话完成漏斗。

## 迭代您的漏斗

在优化某个步骤后（例如简化您的结账页面），使用 [对比](/docs/compare) 洞察来检查转化率在后续期间是否有所提高。

您还可以创建多个漏斗来测试不同的用户路径。例如，比较通过 `/pricing` 进入的用户与通过 `/blog` 进入的用户，看看哪条路径的转化效果更好。
