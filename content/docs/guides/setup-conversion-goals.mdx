---
title: 设置转化目标
---

本指南将引导您定义网站上的成功标准，设置目标来衡量它，并构建漏斗以了解用户流失的位置。

## 步骤 1：定义您的转化

转化是用户采取的任何有意义的行动。常见示例：

| 目标 | 类型 | 值 |
| --- | --- | --- |
| 访问了定价页面 | 查看页面 | `/pricing` |
| 注册了账户 | 触发事件 | `signup` |
| 完成了购买 | 触发事件 | `checkout-complete` |
| 下载了资源 | 触发事件 | `file-download` |

## 步骤 2：设置事件跟踪

如果您的转化是页面视图（如访问 `/pricing`），则不需要额外的跟踪代码。Umami 会自动记录所有页面视图。

对于基于行动的转化，将事件跟踪添加到相关元素：

```html
<button data-umami-event="signup" data-umami-event-plan="free">
  创建账户
</button>
```

或使用 JavaScript：

```js
umami.track('checkout-complete', { revenue: 49.99, currency: 'USD' });
```

## 步骤 3：创建目标

1. 导航到您的网站并打开 **目标** 洞察。
2. 点击 **添加目标**。
3. 选择 **查看页面** 或 **触发事件** 并输入值（例如 `/pricing` 或 `signup`）。
4. 点击 **保存**，然后运行洞察。

目标洞察显示转化率：在选定日期范围内，执行该操作的访客占总访客的百分比。

## 步骤 4：构建漏斗

目标告诉您转化率，但漏斗向您展示用户*在哪里*流失。

1. 导航到 **漏斗** 洞察。
2. 点击 **添加漏斗**。
3. 定义用户应采取的顺序步骤。例如：

| 步骤 | 类型 | 值 |
| --- | --- | --- |
| 1 | 查看页面 | `/` |
| 2 | 查看页面 | `/pricing` |
| 3 | 触发事件 | `signup` |
| 4 | 触发事件 | `checkout-complete` |

4. 设置 **窗口**（例如步骤之间 60 分钟）。
5. 点击 **保存** 并运行洞察。

漏斗显示有多少用户完成了每个步骤以及步骤之间的流失率。如果 1,000 名用户访问了您的主页，但只有 200 名到达定价页面，那就是 80% 的流失率，值得调查。

## 步骤 5：随时间监控

使用 [对比](/docs/compare) 洞察来跟踪您的转化率如何随时间变化。选择 **上一时期** 来比较本周与上周，或 **上一年** 进行季节性比较。

结合 [UTM 跟踪](/docs/guides/measure-campaigns) 来了解哪些营销渠道带来了转化率最高的流量。
