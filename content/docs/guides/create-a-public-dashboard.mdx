---
title: 创建公共仪表盘
---

使用 Umami 的分享 URL 和看板公开分享您的分析数据。这对于开源项目、透明度报告或与没有 Umami 账户的利益相关者分享指标非常有用。

## 选项 1：分享网站的分析数据

公开分享分析数据最快捷的方式是使用分享 URL。

### 步骤 1：创建分享 URL

1. 在 Umami 中导航到您的网站。
2. 点击网站上的 **编辑**。
3. 进入 **分享 URL** 部分。
4. 点击 **添加分享 URL** 并配置您想要分享的视图（流量、行为、增长）。
5. 点击 **保存** 并复制生成的 URL。

分享 URL 提供您网站分析数据的只读视图，任何拥有链接的人无需登录即可访问。

### 步骤 2：分发链接

- 将其添加到项目的 README 中。
- 将其嵌入到您的网站中。
- 在 Slack 频道或电子邮件中分享。

示例：`https://your-umami.example.com/share/abc123/My-Website`

## 选项 2：分享自定义看板

*需要 v3.1.0*

看板让您仅使用重要的指标和组件构建自定义仪表盘，然后公开分享。

### 步骤 1：创建看板

1. 前往 **看板** 并点击 **添加看板**。
2. 选择看板类型：
   - **网站**：限定于单个网站，包含所有特定于网站的组件。
   - **混合**：组合来自多个网站、链接和像素的组件。
3. 给它起一个描述性的名称（例如，“公开统计”或“第一季度营销仪表盘”）。

### 步骤 2：设计看板

1. 点击 **设计** 进入设计模式。
2. 点击 **添加组件** 并选择要显示的内容（例如，网站指标栏、世界地图、事件图表）。
3. 拖动和调整组件大小以创建您想要的布局。
4. 完成后点击 **保存**。

### 步骤 3：分享看板

1. 在 **看板** 列表中，点击看板上的 **分享** 按钮。
2. 复制生成的分享链接。
3. 任何拥有链接的人无需登录即可查看看板。

## 嵌入到您的网站中

将分享 URL 或看板嵌入到 iframe 中：

```html
<iframe
  src="https://your-umami.example.com/share/abc123/My-Website"
  style="width: 100%; height: 800px; border: none;"
  loading="lazy"
  title="Analytics Dashboard"
></iframe>
```

记得设置 `ALLOWED_FRAME_URLS` 环境变量以允许您的域名：

```dotenv
ALLOWED_FRAME_URLS="https://your-website.example.com"
```

## 提示

- 分享 URL 是永久性的，除非您删除它们。请注意您暴露的数据。
- 对于开源项目，链接到您的公共仪表盘可以建立信任并展示项目健康状况。
- 使用看板创建聚焦的仪表盘。例如，创建一个用于“营销指标”（UTM 来源、引荐来源、活动）的看板，另一个用于“产品指标”（功能使用事件、用户流程）。
